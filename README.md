# AK INTEL – Family Shield

Transparent, consent-based family safety app.

## Features planned
- Child location sharing
- App usage reports
- WhatsApp and Instagram notification sender labels (where Android allows)
- Parent dashboard
- Visible and approved camera/microphone sharing

## Privacy
- No private message reading
- No hidden camera or microphone access
- Child can see and revoke permissions

## Platform
Android APK and a separate iOS app.
